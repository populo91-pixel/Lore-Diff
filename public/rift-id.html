    Comment fonctionnent les indices ?

    Classique : vert et ✓ pour un attribut exact, ambre et ≈ pour une correspondance partielle, rouge et × sinon. Le genre est indiqué par Masculin, Féminin ou Autre ; un duo peut réunir les deux genres. Les flèches indiquent si le champion mystère est sorti plus tard ou plus tôt.

    Emoji : un symbole au départ, puis un de plus par erreur. Compétence : icône seule, touche après deux erreurs, nom après quatre. Splash : le cadrage s’élargit après chaque erreur, jusqu’à l’image entière. Citation : la réplique entière est disponible dès le départ.

    Dans chaque mode, un indice facultatif se débloque au troisième essai, puis un autre au cinquième. Leur utilisation apparaît dans le résultat partagé. Les parties quotidiennes restent enregistrées dans ce navigateur. Le mode entraînement n’affecte pas les cinq défis du jour.
